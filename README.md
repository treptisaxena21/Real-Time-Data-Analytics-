# 📊 Real-Time Data Analytics Dashboard

A Streamlit-based dashboard that displays live cryptocurrency prices, weather updates, and stock market data using real-time APIs. The dashboard provides interactive visualizations, automatic data refresh, and customizable settings for monitoring live data.

## 🚀 Features

- 🪙 Live Cryptocurrency Prices (CoinGecko API)
- 🌦️ Real-Time Weather Updates (OpenWeatherMap API)
- 📈 Live Stock Market Data (Alpha Vantage API)
- 📊 Interactive Dashboard
- 🔄 Auto Refresh
- 🔔 Price Alert Notifications
- ⚙️ Customizable Sidebar Settings

## 🛠️ Technologies Used

- Python
- Streamlit
- Pandas
- Requests
- CoinGecko API
- OpenWeatherMap API
- Alpha Vantage API

## 📦 Installation

1. Clone the repository:
   ```bash
   git clone <repository-url>
   ```

2. Navigate to the project folder:
   ```bash
   cd <repository-folder>
   ```

3. Install the required libraries:
   ```bash
   pip install streamlit pandas requests
   ```

4. Run the application:
   ```bash
   streamlit run app.py
   ```

## 🔑 API Keys

- **CoinGecko API:** No API key required.
- **OpenWeatherMap API:** Free API key required.
- **Alpha Vantage API:** Free API key required.

## 📸 Dashboard

The dashboard provides three sections:
- Cryptocurrency
- Weather
- Stock Market
